# 🍕 Telegram-бот «Пицца Мафия»

Готовый коммерческий Telegram-бот для автоматизации приема заказов в пиццерии. Работает как дополнительный канал продаж, снижая нагрузку на колл-центр.

## 🚀 Основные возможности

### Для клиента
* **Интерактивное меню:** Вся пицца, закуски и напитки с описанием и ценами в одном сообщении.
* **Умная корзина:** Изменение количества, удаление товаров, проверка минимальной суммы заказа.
* **Быстрое оформление:** Бот запоминает адрес и телефон, позволяя оформить повторный заказ в пару кликов.
* **Выбор оплаты:** Наличными курьеру или картой (с терминалом).
* **Промокоды:** Ввод и проверка скидочных кодов.
* **Статусы и история:** Клиент видит этапы заказа и может повторить любой прошлый заказ.

### Для администратора (Панель управления)
* **Прием заказов:** Мгновенные уведомления с полной информацией и кнопками смены статуса.
* **Управление меню:** Изменение цен и скрытие товаров (стоп-лист).
* **Маркетинг:** Создание промокодов и массовая рассылка клиентам.
* **Статистика:** Выручка, количество заказов, средний чек и рейтинг.
* **Интеграция с Google Sheets:** Автоматическое дублирование заказов в таблицу для отчетности (работает в фоне).

## 🛠 Технологии
* Python 3.10+
* Aiogram 3.x
* Aiosqlite (SQLite)
* Aiohttp (для вебхуков)
